# 하늘밭 농업 기상 대시보드

농업인이 현재 기상, 지역 지도, 예보 비교와 농작업 정보를 큰 탭으로 확인할 수 있는 반응형 웹 대시보드입니다.

## 실행

저장소 루트에서 정적 웹 서버를 실행하거나 Vercel에 저장소를 연결하세요. 별도 빌드 명령은 필요하지 않습니다.

```powershell
python -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다. 위치 기능과 배포 환경은 HTTPS가 필요합니다.

## 카카오 지도

`config.js`에 카카오 개발자 콘솔의 JavaScript 키를 설정하고, 카카오 개발자 콘솔에서 `localhost` 및 배포 도메인을 허용 목록에 등록하세요. 지도는 키가 없거나 SDK를 불러오지 못하면 안내 메시지를 표시합니다.

## 기상 정보와 Gemini

현재 기상 수치는 화면 설계용 예시 데이터입니다. 기상청·Windy·Open-Meteo 및 실제 관측 API는 아직 연결되지 않았습니다. 농작업 판단 탭에서 질문하면 현재 대시보드 기상정보와 질문을 Gemini API로 보내고, 답변을 화면에 바로 표시합니다. 서버리스 인스턴스별로 1분에 IP당 최대 10회를 제한하며, 이 제한은 인스턴스 간 공유되지 않는 최선 노력 방식입니다.

Vercel 프로젝트 설정의 **Settings → Environment Variables**에 `GEMINI_API_KEY`를 등록하고 재배포하세요. 이 키는 API 함수에서만 사용하며 브라우저 번들에 포함하지 않습니다. Gemini 상담은 사용자 질문과 현재 표시 중인 날씨·지역 정보를 Google Gemini로 전송합니다.

로컬에서 서버리스 API를 테스트하려면 Vercel CLI로 개발 서버를 실행하고 `GEMINI_API_KEY`를 로컬 환경 변수로 설정하세요. Python 정적 서버는 `/api/ask-gemini`를 실행하지 않습니다.

실제 비밀 API 키를 브라우저 코드나 공개 저장소에 저장하지 마세요.
